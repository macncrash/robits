Settle before ordering

  1. Motor code and inductance. Confirm KBM-17H01-B00 with Kollmorgen (the nearest code seen listed was KBMS-17H01-C00) and its line-to-line inductance: the AKD needs at least 2.5 mH at 240 V.
  2. Motor PTC with BiSS-C. Ask Kollmorgen whether the AKD reads the PTC on X10/8–9 with FB1.SELECT 34. If not, add a DIN-rail PTC relay (not yet chosen).
  3. Planet pins. The needles run on the pins. Standard hardened dowels are m6, which eats some of the HK0609's clearance; INA asks for h6. Confirm with Schaeffler or buy h6 pins and tighten the carrier holes.
  4. Drive generation. Ask a Kollmorgen distributor whether NBAN, NCAN or NDAN is current for the AKD-P00306.
  5. Pendant fabrication files. Export fabrication.zip from the STEVE circuit (revision 32) yourself: STEVE's API can't download it.

When the parts arrive

  • Check each machined part against its drawing's inspection note; ask for the CMM and gear reports.
  • Build it with ASSEMBLY.md: sub-assemblies, the gear stage, the housing, the rear bearing and encoder, the pedestal.
  • Power it up with TEST.md: insulation and winding checks, drive limits (5.9 A peak, 3.0 A continuous), first spin, E-stop, run-in, backlash.
  • Bring up the pendant per pcb/README.md before connecting it to the drive.
